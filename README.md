# ₹ WiseRupee

AI-powered personal finance planner built for the **Compute50 Golden Jubilee National Level Hackathon** (PSG College of Technology).

Splits your monthly salary by life stage (bachelor or married, with or without children), reads your spending pattern, and suggests an investment plan.

## Features
- Life-stage budget split
- Expense tracker with categories
- Spending-pattern insights (Saver, Weekend spender, Stretched thin)
- Investment plan: emergency fund, SIP, PPF, gold
- Savings goal planner
- "Can I afford it?" purchase checker

## Run it
No install needed. Download the files and open `index.html` in a browser.

## Files
| File | Language | Purpose |
| --- | --- | --- |
| `index.html` | HTML | Page structure |
| `style.css` | CSS | Styling |
| `script.js` | JavaScript | Budget engine, insights and app logic |

Data is saved only in your browser (localStorage). Educational guidance, not financial advice.
