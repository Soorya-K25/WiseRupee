## 📌 About the Project

**WiseRupee** is a personal finance planning project designed to help individuals organise their financial information, review spending and plan budgets and savings goals. Its product direction focuses on making everyday money management easier to understand through a clear web-based experience.

🔗 **Live Application:** https://rupee-wise-life-planner.lovable.app/

## 🎯 Problem Statement

Managing monthly income, daily expenses, household commitments and savings goals can become difficult when financial information is scattered. WiseRupee aims to bring personal finance planning activities together in one accessible application.

## ✨ Project Scope

The project is centred around these planned product areas. Please verify each feature against the current deployed application before presenting it as fully implemented.

- **Personalised Planning** — financial planning informed by a user's circumstances.
- **Expense Management** — organise and review expense information.
- **Budget Planning** — structure monthly income across spending and savings categories.
- **Spending Insights** — make spending patterns easier to understand.
- **Savings Goals** — plan and monitor progress towards financial targets.
- **Financial Assistant** — optional conversational guidance, if enabled in the current build.
